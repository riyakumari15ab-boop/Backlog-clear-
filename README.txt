BACKLOG CLEAR — PHONE VERSION

This is a Progressive Web App (PWA).
The files need to be opened from a web address (hosting) for Chrome's "Add to Home screen" / install behavior to work reliably.

Features:
- Backlog for Physics, Chemistry, Biology
- Progress dashboard
- Simple smart daily plan
- Focus timer
- Daily motivation
- Local device storage

No account or server is required for the current prototype.
